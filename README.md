# Reedar

Macで使う、3ペインのRSSリーダー。選択した記事を、既存のClaude Code / Codex CLIを通じて日本語で要約し、続けて質問できます。

現状: RSS閲覧とCodex（GPT-5.3-Codex-Spark）の要約・追加質問を実機確認済み。Claude Codeの実接続確認はユーザー指定で保留。Antigravityは接続対象に追加し、CLI検出まで対応しています。記事の送信は連携準備中です。完了条件と検証結果は[VALIDATION.md](VALIDATION.md)を参照してください。

## 起動

```sh
bun install
bun run start
```

初回はElectronの実行ファイルがダウンロードされます。起動するとMacのウィンドウが開きます。署名・配布用パッケージは作成していません。

画面だけをブラウザで開く開発モード:

```sh
bun run dev
```

ターミナルに表示されたURLを開いてください。起動ごとにセッションとポートが変わります。

## 読む・整理する

- 左上の「＋」からRSS / AtomのURLを登録します。通常のWebページからのフィード自動検出はありません。
- フォルダを作り、「フィードを整理」で保存先を変更できます。フォルダ名の変更にも対応しています。
- 記事を選ぶと既読になります。本文上部から未読へ戻す・スターを付ける・原文を開く操作ができます。
- 記事一覧の検索は、取得済みのタイトルと本文が対象です。
- `J` / `K` または上下キーで前後の記事へ移動、`S`でスター、`M`で既読切り替え、`/`で検索、`N`でフィード追加。文字入力中は記事操作に使いません。

RSSに抜粋しか含まれない場合は、抜粋を表示・送信します。全文の再抽出や外部情報の調査は行いません。AIの回答も取得済み本文に限定します。

## AIと読む

本文上部の「AIと読む」を開き、Claude CodeかCodexを選択します。「この記事を日本語で要約して」または自由な質問を送信してください。追加質問は同じ記事・同じエージェントの会話に残ります。送信は `⌘ Enter` でも実行できます。

回答は生成中から表示し、停止ボタンで中止できます。認証が必要な場合は「確認待ち」、処理エラーは「失敗」と表示します。確認待ちの依頼も中止できます。同時実行は最大2会話です。回答処理そのものでは既読状態を変えません。

「エージェント接続」でログイン状態を確認できます。必要な場合はターミナルでログインした後、「接続を再確認」を押してください。

```sh
claude auth login
codex login
```

Codexは `gpt-5.3-codex-spark` を指定します。CLIが別モデルを返した場合は実行を中止し、黙って別モデルへ切り替えません。新しい回答にはモデル名を保存し、過去のモデル不明な回答と区別します。

CodexはChatGPTログイン、Claude Codeは既存のサブスクリプションによるログインを使います。APIキーを必須にする経路はありません。CLIの既存契約の利用枠を消費します。

このMacではCodexのアプリ同梱CLI（0.153.4）を使用して実接続を確認しました。アプリ同梱CLIを優先し、次にPATHと一般的なインストール先を探します。必要なら起動時に `REEDAR_CODEX_BIN` / `REEDAR_CLAUDE_BIN` で実行ファイルを指定できます。既存のCLI設定ファイルは書き換えません。

Antigravityの `agy` もPATH・一般的なインストール先から検出します（`REEDAR_ANTIGRAVITY_BIN` で指定可能）。現行CLIで読書中のファイル・外部ツール操作を無効化できる方法を確認できなかったため、「エージェント接続」では「連携準備中」と表示します。インストール検出を認証済み・利用可能とは扱いません。Antigravityへの記事送信は実行せず、ユーザー全体のCLI設定も変更しません。

## 保存

- Mac版: `~/Library/Application Support/Reedar/reader.json`
- 開発モード: `.data/dev/reader.json`（`REEDAR_DATA_DIR`で変更可能）

フィード、取得済み記事、フォルダ、既読、スター、会話をローカルJSONに保存します。会話には最初に送った記事の写しを残すため、後でフィードが更新されても会話の前提を保持できます。保存は一時ファイルからの置き換えで行います。通常終了時は生成を停止して部分回答を保存します。クラッシュ時は最後の保存以降の部分回答が失われる場合があり、未完了の応答は次回起動時に失敗として表示します。

保存ファイルは暗号化していません。OSユーザーのファイル権限で保護しています。破損したJSONを空のライブラリで上書きせず、起動エラーにします。

## セキュリティと範囲

記事のHTMLからスクリプト、イベントハンドラ、フォーム、埋め込みを除去します。画像はローカルプロキシ経由で取得し、フィード取得と同じくローカル・プライベート宛先、DNSによる内部宛先、リダイレクトを検査します。

画面は認証付きの127.0.0.1サーバーから配信します。HostとOriginを検査し、外部サイトからの操作を拒否します。ElectronのNode連携を無効化し、サンドボックスとCSPを有効にしています。

記事と履歴は信頼できない引用データとしてモデル入力に渡します。選択した記事と会話はAI提供元に送られます。認証情報はCLIに管理させ、入力へ含めません。読書セッションではシェル・MCP・プラグイン等を無効化し、追加のツール要求や権限拡大を拒否します。CLI側の仕様変更に対しては再検証が必要です。

Inoreader等の同期、OPML移行、モバイル、定期自動処理、記事からコードを変更する機能、購読の削除、公開配布は今回の範囲に含めていません。

## 検証

```sh
bun run check
```

型チェック、自動テスト、ブラウザ用とElectron用のビルドを実行します。テストはネットワーク・プロセス・UIの境界を検証し、実際のAIサービスへリクエストを送りません。
