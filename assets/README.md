# App icon

`icon.png` is Reedar's 1024 × 1024 RGBA master icon. The open book represents reading; the apricot arcs represent RSS feeds. Its graphite, ivory, and apricot palette matches the application.

Generated with the built-in image generation tool on September 11, 2026, then resized with macOS `sips` for application packaging. Transparent pixels outside the rounded tile are preserved. This icon is used in the development Dock; packaged macOS builds use the ICNS representation generated from the same PNG.
